Mobile bumps (compared to desktop):
↑ label 12→18 · micro 10→14 · body 12→15 · body-sm 10→13 (all bigger).
display tiers slightly smaller on mobile so KPI cards fit a 2-col grid (disp-md 34→28 etc.).
--fs-input on mobile = 16px — required to prevent iOS Safari auto-zoom on input focus.

FONT FAMILY ASSIGNMENT

Two pixel-family fonts, one mono-clean. Press Start 2P stays for the iconic chunky 8-bit headings; VT323 (CRT terminal) takes over labels because it's far more legible at small sizes; Share Tech Mono carries readable body text + inputs. 
:root {
  --ff-title:    'Press Start 2P', monospace;  /* 10px headings: PROFILE, ANALYTICS */
  --ff-section:  'Press Start 2P', monospace;  /* 8px section + button labels */
  --ff-label:    'VT323', monospace;           /* 12/18px form labels, table th */
  --ff-micro:    'VT323', monospace;           /* 10/14px tiny badges + day numbers */
  --ff-body:     'Share Tech Mono', monospace; /* 12/15px values + meta */
  --ff-input:    'Share Tech Mono', monospace; /* 13/16px form inputs */
  --ff-display:  'VT323', monospace;           /* big numbers: clock, KPI, P&L */
}
